# Source history

The development checkout was initialized with Git and the initial implementation was committed as one honest baseline. No historical student iterations or peer reviews were fabricated.

The ZIP includes `source-history.bundle`, a portable copy of that initial commit. Git is not required to run the application. If you have Git installed and want to restore its version history, run this from the extracted `InternTrack` directory:

```bash
git clone source-history.bundle ../InternTrack-with-history
```

Run the restored project from the new folder after installing its dependencies. Continue making actual commits as you review, change, and test the project. No GitHub repository was created or published by this session.
