# Suggested 5-minute demonstration

Use fictional demo data. This is a demonstration plan, not a record of a completed presentation.

1. **Problem (30 sec):** “InternTrack helps students keep internship applications, interview dates, and progress in one place.”
2. **Overview (45 sec):** Show status cards, the application list, and upcoming interviews. Explain that cards count the whole account while search filters the list.
3. **Add (60 sec):** Create an application for a fictional company. Show the company, position, date, status, and notes. Submit once with a missing company to demonstrate validation, then correct it.
4. **Update (45 sec):** Edit the application to Interview and add a future local date/time. Return to Overview and show the new interview.
5. **Search (30 sec):** Search the company and filter by Interview. Clear filters.
6. **Privacy (30 sec):** Explain ownership checks; if time permits, sign into a separate prepared account and show its independent workspace.
7. **Testing/design (45 sec):** Show the component diagram, test results, and requirement-to-test mapping. Explain one concrete test: a second account cannot edit or delete the first account's record by changing a URL.
8. **Close (15 sec):** Explain one limitation and future enhancement: local classroom deployment now; CSV export or calendar view later.

Before presenting: run the application yourself, rehearse, complete manual acceptance checks, and replace these prompts with your own explanation of what you understand and contributed.
